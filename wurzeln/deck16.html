Rechnen mit Wurzeln

Ein DIN-A4-Blatt hat ein Seitenverhältnis von genau √2. Falte es einmal — und du bekommst wieder genau dasselbe Seitenverhältnis (DIN A5). Das ist kein Zufall, sondern eine direkte Folge der Rechengesetze für Wurzeln, die du jetzt lernst.

⚠️ Anti-Regel √(a+b) ≠ √a + √b

√(9+16) = √25 = 5 — aber √9 + √16 = 3 + 4 = 7. Nicht dasselbe!
Der wichtigste Fehler beim Rechnen mit Wurzeln: Man darf eine Summe NICHT einfach „unter der Wurzel auseinanderziehen". Wurzeln sind KEINE lineare Operation wie die Multiplikation.
  • Merk dir dieses Gegenbeispiel — es widerlegt die Falle sofort, wann immer sie auftaucht.

Addition & Subtraktion von Wurzeln

Nur Wurzeln mit GLEICHEM Radikanden dürfen addiert bzw. subtrahiert werden — genau wie bei Termen mit derselben Variablen: x·√a ± y·√a = (x±y)·√a.
  • 5√2 + 6√2 = 11√2 · 6√2 − 10√2 = −4√2
  • 6√5 + 10√x = 16√x ist FALSCH — die Radikanden 5 und x sind verschieden, hier bleibt nur 6√5+10√x stehen.

Multiplikation von Quadratwurzeln

Das Produkt zweier Quadratwurzeln ist eine Quadratwurzel, deren Radikand das Produkt der beiden Radikanden ist: √a · √b = √(a·b) mit a,b ∈ ℝ₀⁺.
  • √2 · √50 = √100 = 10 · √3 · √12 = √36 = 6 · 2√7 · 3√2 = 6√14

Einen Faktor unter die Wurzel ziehen

Ein Faktor vor der Wurzel wird unter die Wurzel geschrieben, indem er quadriert wird: a√b = √(a²·b) mit a,b ∈ ℝ₀⁺.
  • 2√3 = √(2²·3) = √(4·3) = √12 · 4√2 = √(16·2) = √32 · 3√5 = √(9·5) = √45

Teilweises Radizieren

√50 = √25 · √2 = 5√2 — die Quadratzahl 25 „verlässt" die Wurzel als 5
Die Umkehrung: eine Quadratwurzel wird in ein Produkt aus Faktoren zerlegt, wobei aus einem Faktor (einer Quadratzahl) die Wurzel gezogen werden kann.
  • √8 = √(4·2) = √4·√2 = 2√2 · √12 = √(4·3) = 2√3 · √75 = √(3·25) = 5√3

📐 Schritt für Schritt √288 teilweise radizieren

Aufgabe: Radiziere √288 teilweise.
Größte Quadratzahl finden: 288 = 2·144 — und 144 ist eine Quadratzahl (12²=144).
Zerlegen: √288 = √(2·144) = √2 · √144.
Wurzel ziehen: √144 = 12, also √2 · √144 = √2 · 12.
Antwortsatz: √288 = 12√2.

Division von Quadratwurzeln

Der Quotient zweier Quadratwurzeln ist eine Quadratwurzel, deren Radikand der Quotient der beiden Radikanden ist: √a / √b = √(a/b) mit a ∈ ℝ₀⁺, b ∈ ℝ⁺.
  • √50 / √2 = √25 = 5 · √3 / √12 = √(1/4) = 1/2 · 3√6 / √2 = 3√3

Rationalmachen des Nenners (Teil 1)

Steht im Nenner eines Bruchs eine einzelne Wurzel, wird der Bruch mit genau dieser Wurzel erweitert — die Wurzel im Nenner verschwindet, da √b·√b = b: a/√b = (a·√b)/b mit a ∈ ℝ, b ∈ ℝ⁺.
  • 1/√2 = (1·√2)/(√2·√2) = √2/2 · 10/√5 = (10·√5)/5 = 2√5

Rationalmachen des Nenners (Teil 2)

Steht im Nenner eine SUMME mit einer Wurzel (z. B. x+√2), wird mit der Differenz erweitert (x−√2) — dadurch greift die dritte Binomische Formel (a+b)(a−b)=a²−b² und die Wurzel verschwindet: a/(b+√x) = (a·(b−√x)) / (b²−x).
  • 🌉 Brücke zu Kapitel 4.5: genau die dritte Binomische Formel aus dem letzten Kapitel macht diesen Trick möglich!

📐 Schritt für Schritt 5/(x+√2) rational machen

Aufgabe: Mache den Nenner des Bruchs 5/(x+√2) rational (x ≠ −√2).
Mit der Differenz erweitern: Erweitere mit (x−√2): 5/(x+√2) = (5·(x−√2)) / ((x+√2)·(x−√2)).
3. Binom anwenden: (x+√2)·(x−√2) = x² − (√2)² = x² − 2.
Antwortsatz: 5/(x+√2) = (5·(x−√2)) / (x²−2) — der Nenner enthält keine Wurzel mehr.

Potenzieren von Wurzeln

Eine Wurzel wird mit einem Exponenten n potenziert, indem der Radikand mit n potenziert wird: (√a)ⁿ = √(aⁿ) mit a ∈ ℝ₀⁺.
  • (√2)³ = √(2³) = √8 · (√3a)⁵ = √((3a)⁵) = √(3⁵a⁵) = √(243a⁵)
  • Umgekehrt gilt auch: steckt eine Potenz UNTER der Wurzel, kann direkt aus der Basis die Wurzel gezogen werden: √(4⁵) = (√4)⁵ = 2⁵ = 32.

💡 Eselsbrücke

„Wurzeln sind wie Türsteher bei Multiplikation und Division: die dürfen zusammen (√a·√b=√(ab), √a/√b=√(a/b)) — aber bei PLUS und MINUS bleibt jede Wurzel für sich allein, außer sie haben denselben Radikanden." Der Klassiker-Fehler √(a+b)=√a+√b bricht genau diese Türsteher-Regel.

🔧 Praxisbeispiel DIN-Papierformate

DIN A4 halbiert ergibt DIN A5 — mit demselben Seitenverhältnis √2
Bei jedem Papierblatt nach DIN-Norm gilt: die längere Seite l_y ist genau √2-mal so lang wie die kürzere Seite l_x (l_y = √2 · l_x). Halbiert man das Blatt an der langen Seite, bekommt das neue Blatt WIEDER dasselbe Seitenverhältnis √2 — deshalb passt A5 wieder perfekt zu A4.
  • Druckereien und die Papierindustrie verlassen sich weltweit auf genau diese Eigenschaft der Quadratwurzel aus 2.

🎯 Prüfungs-Check — das musst du KÖNNEN

  • Wurzeln multiplizieren, dividieren, teilweise radizieren können.
  • Nenner rational machen — auch bei einer Summe im Nenner (3. Binom).
  • Den Klassiker-Fehler √(a+b)=√a+√b erkennen und korrigieren können.
Kapitel-Brücke — Transferaufgabe mit Binomen: „Berechne (√3+√2)·(√3−√2) mithilfe der dritten Binomischen Formel." → (√3)²−(√2)² = 3−2 = 1. Die Binomischen Formeln funktionieren mit Wurzeln genauso wie mit Zahlen und Variablen!
