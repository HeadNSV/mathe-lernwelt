FUNKTIONENSCHAREN · Teil 1

Was ist eine Funktionenschar?

Ein Handytarif mit fest eingestelltem Grundpreis ist eine Gerade. Ein Handytarif, bei dem der ANBIETER den Grundpreis noch frei wählen kann, ist keine Gerade mehr — es ist eine ganze Familie von Geraden. Genau das ist eine Funktionenschar.

Ein Parameter macht aus EINER Geraden UNENDLICH viele

fk(x) = x + k mit k∈{−2;−1;0;1;2} — für jeden Wert von k entsteht eine eigene, parallele Gerade.

Funktionenschar & Parallelenschar

Ein Funktionsterm mit einer zusätzlichen Variablen (dem Parameter oder der Formvariablen) beschreibt eine Menge von Funktionen — man nennt sie Funktionenschar.
Verlaufen alle Geraden einer Schar parallel zueinander (gleiche Steigung, wie im Beispiel oben), spricht man von einer Parallelenschar.

🌉 Brücke Parameter k vs. Variable x

⚠️ Die zentrale Fehlvorstellung: x ist die LAUFENDE Variable — sie bewegt sich stetig ENTLANG einer einzelnen Geraden. k ist der Parameter — er WÄHLT aus, welche Gerade der Schar du überhaupt betrachtest. Setzt du einen Wert für k ein, bekommst du eine ganz normale lineare Funktion mit nur noch EINER Variablen (x).
Genau dasselbe Prinzip kennst du schon von der Formvariablen bei Gleichungen — dort wählte die Formvariable eine bestimmte Gleichung aus einer Familie aus. Hier wählt sie geometrisch eine bestimmte Gerade.

📐 Schritt für Schritt Eine einzelne Funktion aus der Schar bestimmen

Aufgabe: Gegeben ist fk(x) = 2x + k mit Dfk=ℝ und k∈ℝ. Bestimme f₃.
Schritt 1 — k=3 in den Term einsetzen: f₃(x) = 2x + 3.
Schritt 2 — fertig: f₃ ist jetzt eine ganz normale lineare Funktion mit m=2 und t=3.

Geradenbüschel & Büschelpunkt

Manche Scharen sind KEINE Parallelenscharen — ihre Steigung hängt selbst vom Parameter ab. Trotzdem können alle Geraden einen gemeinsamen Punkt teilen. So einen Graphen nennt man Geradenbüschel, den gemeinsamen Punkt Büschelpunkt.
Beispiel: hk(x) = (k−3)x + 6. Egal welches k eingesetzt wird — der konstante Teil bleibt immer 6. Also gehen ALLE Geraden dieser Schar durch den Punkt T(0|6).

Besondere Geraden einer Schar

  • Parallel zur x-Achse: den Steigungsterm gleich 0 setzen und nach k auflösen.
  • Durch einen bestimmten Punkt P: die Koordinaten von P einsetzen und nach k auflösen.
  • Mit einer bestimmten Nullstelle: den gewünschten x-Wert einsetzen, Funktionswert gleich 0 setzen, nach k auflösen.
⚠️ Eine Schar deckt NICHT automatisch jede erdenkliche Gerade ab — z.B. muss keine der Geraden aus pk(x)=(k−1)x+3 zwangsläufig senkrecht zu einer vorgegebenen Geraden stehen, nur weil die Schar unendlich viele Geraden enthält.

📐 Schritt für Schritt Besondere Gerade einer Schar finden

Aufgabe: Gegeben ist pk(x) = (k−1)x + 3. a) Welches k macht die Gerade parallel zur x-Achse? b) Welches k liefert die Gerade durch P(2|7)?
a) Steigungsterm = 0: k−1=0 ⟺ k=1 → p₁(x)=3 (waagrecht).
b) Punkt einsetzen: pk(2)=7 ⟺ (k−1)·2+3=7 ⟺ 2k+1=7 ⟺ k=3.
Probe: p₃(x)=2x+3 → p₃(2)=4+3=7 ✓.

Nullstellen einer Funktionenschar

Genau wie bei einer einzelnen Funktion wird die Nullstelle über fk(x)=0 berechnet — nur hängt das Ergebnis jetzt vom Parameter ab.
Beispiel: fk(x) = 3x − k + 2. Nullstelle: 3x−k+2=0 ⟺ 3x=k−2 ⟺ x=(k−2)/3. Da der x-Koeffizient (3) NICHT vom Parameter abhängt, gilt diese Formel für JEDEN Wert von k — ohne Fallunterscheidung.

💡 Eselsbrücke

„k wählt die Gerade, x läuft auf ihr entlang." Und: „Setz k ein — dann ist es wieder ganz normale Mathe."

🔧 Praxisbeispiel Stücklohn mit variablem Sockel

Ein Handwerksbetrieb zahlt pro gefertigtem Stück einen festen Akkordlohn, dazu einen Sockelbetrag, der sich je nach Auftrag unterscheidet. Der Sockelbetrag ist genau der Parameter k einer Lohn-Funktionenschar — für jeden konkreten Auftrag entsteht daraus eine eigene, ganz normale lineare Lohnfunktion.

Schätz mal: durch welchen Punkt?

Die Schar gk(x) = kx − 5 hat für JEDES k denselben konstanten Anteil. Durch welchen Punkt auf der y-Achse verlaufen daher ALLE Geraden dieser Schar? (Gib nur die y-Koordinate an.)

  2. Welches k macht die Gerade aus gk(x)=(k+2)x−1 zu einer Ursprungsgeraden? (Hinweis: eine Ursprungsgerade hat t=0.)
    Lösung anzeigenDer y-Achsenabschnitt ist hier fest −1, NIE 0 — diese Schar enthält also GAR KEINE Ursprungsgerade, egal welches k man wählt.
  3. Zeige, dass alle Geraden aus pk(x)=k·(x+1)−3 durch denselben Punkt verlaufen, und gib ihn an.
    Lösung anzeigenBei x=−1 wird der Klammerausdruck (x+1) zu 0, egal welches k gewählt wird → pk(−1)=k·0−3=−3 für JEDES k → Büschelpunkt (−1|−3).

🎯 Prüfungs-Check — das musst du KÖNNEN

  • Parameter k und Variable x sicher unterscheiden — nie verwechseln, welche Rolle welcher Buchstabe hat.
  • Eine einzelne Funktion aus einer Schar bestimmen — k einsetzen.
  • Büschelpunkt erkennen — wenn der konstante Anteil parameterunabhängig ist.
