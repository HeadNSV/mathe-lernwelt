Fallunterscheidung & Schnittpunkte

Was, wenn der Parameter selbst im Steigungsterm steckt und Null werden könnte? Dann darf man nicht blind weiterrechnen — genau hier braucht es eine Fallunterscheidung.

Wann braucht man eine Fallunterscheidung?

Wird eine Gleichung durch einen Term DIVIDIERT, der den Parameter enthält, muss zuerst der Parameterwert ausgeschlossen werden, für den dieser Term Null wird. Dieser Sonderfall wird anschließend SEPARAT berechnet.
⚠️ Der Klassiker-Fehler: einfach durch den Parameter-Term teilen, ohne zu prüfen, ob er 0 werden kann.

📐 Schritt für Schritt Nullstelle MIT Fallunterscheidung

Aufgabe: Bestimme die Nullstelle von gk(x) = (k−2)/3 · x + 1.
Schritt 1 — gleich Null setzen: (k−2)/3 · x + 1 = 0 ⟺ (k−2)x = −3.
Schritt 2 — durch (k−2) teilen, aber nur für k≠2: x = −3/(k−2), diese Rechnung gilt für k≠2.
Schritt 3 — Sonderfall k=2 separat: g₂(x) = 0·x+1 = 1 (konstant, ≠0) → g₂ hat KEINE Nullstelle.

Der Sonderfall: keine oder unendlich viele Nullstellen?

Wird die Funktion im Sonderfall zu einer KONSTANTEN (kein x mehr übrig), gibt es zwei Möglichkeiten:
  • Konstante ≠ 0 → die Gerade verläuft parallel zur x-Achse, ohne sie zu berühren → keine Nullstelle (Beispiel oben: g₂(x)=1).
  • Konstante = 0 → die Funktion IST identisch die x-Achse → unendlich viele Nullstellen. Beispiel: hk(x)=(k+1)/4·x. Sonderfall k=−1: h−1(x)=0·x=0 — jeder x-Wert ist Nullstelle.

🌉 Brücke Dieselbe Logik wie bei Gleichungen mit Formvariable

Diese Fallunterscheidung ist dir nicht neu: schon bei linearen Gleichungen mit Formvariable musstest du prüfen, ob der Koeffizient vor x zu 0 werden kann, bevor du teilen durftest. Hier taucht exakt dieselbe Regel wieder auf — nur jetzt geometrisch als „hat diese Gerade der Schar überhaupt eine Nullstelle?" gedeutet.

Büschelpunkt — auch abseits der y-Achse

Der Büschelpunkt einer Schar muss NICHT auf der y-Achse liegen. Trick: schreibe die Schar in der Form pk(x) = k·(x−a) + b — dann verschwindet der Parameter k automatisch bei x=a, und JEDE Gerade der Schar geht durch den Punkt (a|b).
Beispiel: pk(x) = k·(x−2) + 5. Bei x=2 wird die Klammer 0, also pk(2) = k·0+5 = 5 — für JEDES k. Büschelpunkt: (2|5).

📐 Schritt für Schritt Büschelpunkt einer Schar bestimmen

Aufgabe: Zeige, dass alle Geraden aus rk(x) = k·x − 2k + 5 durch einen gemeinsamen Punkt verlaufen.
Schritt 1 — nach k ausklammern: rk(x) = k·(x−2) + 5.
Schritt 2 — Klammer-Nullstelle finden: die Klammer (x−2) wird 0 bei x=2 — unabhängig von k.
Schritt 3 — Büschelpunkt angeben: rk(2) = k·0+5 = 5 für jedes k → Büschelpunkt (2|5).

Schnittpunkt einer Schar mit einer festen Geraden

Genau wie bei zwei einzelnen Geraden werden die Funktionsterme gleichgesetzt — nur bleibt der Parameter k in der Lösung stehen. Der Schnittpunkt Sk hängt dann vom Wert des Parameters ab.

📐 Schritt für Schritt Schnittpunkt Schar mit fester Gerade

Aufgabe: Schar sk(x) = kx + 3, feste Gerade g(x) = 2x − 1. Berechne den Schnittpunkt in Abhängigkeit von k.
Schritt 1 — gleichsetzen: kx+3 = 2x−1 ⟺ (k−2)x = −4.
Schritt 2 — durch (k−2) teilen, für k≠2: xS = −4/(k−2).
Schritt 3 — Sonderfall k=2: s₂(x)=2x+3 vs. g(x)=2x−1 — gleiche Steigung, unterschiedliches t → echt parallel, KEIN Schnittpunkt.

Anwendungsaufgabe — Tankfüllzeit-Familie

Ein Heizöltank mit 3000 Litern Fassungsvermögen wird von einer Zapfpistole geleert. Je nach Pumpendurchsatz p (Liter/Minute) ergibt sich eine eigene lineare Funktion: yp(t) = 3000 − p·t. Der Pumpendurchsatz p ist hier der Parameter der Schar.
  • Nullstelle (Tank leer): 3000 − p·t = 0 ⟺ t = 3000/p.
  • Für p=100 l/min: t = 30 Minuten.
  • Antwortsatz: Bei einem Pumpendurchsatz von 100 Litern pro Minute ist der Tank nach 30 Minuten leer.

💡 Eselsbrücke

„Teilst du durch etwas mit Parameter — erst ausschließen, dann NICHT vergessen: der Sonderfall zählt genauso zum Ergebnis." Und: „Ausklammern zeigt den Büschelpunkt — k·(x−a)+b trifft immer (a|b)."

🔧 Praxisbeispiel Federkennlinien in der Werkstatt

Verschiedene Fahrzeugfedern haben unterschiedliche Federkonstanten k — die Kennlinie „Kraft in Abhängigkeit vom Federweg" ist damit eine Funktionenschar. Ein Konstrukteur, der prüft, bei welcher Federkonstante eine bestimmte Kraft bei einem bestimmten Federweg erreicht wird, löst genau eine Schar-Aufgabe wie in diesem Deck.
