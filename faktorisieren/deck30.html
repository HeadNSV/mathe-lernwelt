Bruchgleichungen

Bei einer Bruchgleichung steht die Variable im Nenner — und das bedeutet: bevor du überhaupt zu rechnen beginnst, musst du wissen, welche Werte VERBOTEN sind. Genau das ist der Kern dieses Themas.

Definitionsmenge ZUERST

Eine Bruchgleichung ist eine Gleichung, in der die Variable im Nenner mindestens eines Bruchterms steht. Jeder Nenner, der 0 werden könnte, markiert eine Verbotsstelle — diese Werte gehören NICHT zur Definitionsmenge D. Die Definitionsmenge wird immer ZUERST bestimmt, bevor du zu rechnen beginnst.

🌉 Brücke Zwei alte Bekannte kehren zurück

  • Die Definitionsmenge eines Bruchterms kennst du schon aus dem Kapitel Terme — dort ging es nur um EINEN Term, jetzt geht es um eine ganze GLEICHUNG mit Bruchtermen.
  • Die Schreibweise D = ℝ\{2; −5} ist reine Mengenschreibweise aus dem allerersten Kapitel — eine Menge, aus der einzelne Elemente entfernt wurden.

📐 Schritt für Schritt Definitionsmenge bestimmen

Aufgabe: Bestimme D für 3/(x−2) + 1/(x+5) = 2.
Schritt 1 — jeden Nenner betrachten: x−2 und x+5.
Schritt 2 — jeden Nenner = 0 setzen: x−2=0 → x=2. x+5=0 → x=−5.
Schritt 3 — Definitionsmenge angeben: D = ℝ\{2; −5}. Erst JETZT darf gerechnet werden.

Lösen über den Hauptnenner

Um alle Brüche auf einmal loszuwerden, wird die gesamte Gleichung mit dem Hauptnenner (dem kgV aller Nenner) multipliziert. Übrig bleibt eine gewöhnliche Gleichung ohne Brüche — die kannst du mit den Verfahren aus den letzten Kapiteln lösen.
⚠️ Manchmal muss ein Nenner erst FAKTORISIERT werden, um den Hauptnenner zu erkennen — genau das Werkzeug aus den ersten beiden Decks dieses Kapitels.

📐 Schritt für Schritt Bruchgleichung lösen

Aufgabe: Löse 1/(x−1) + 2/(x+1) = 3/(x²−1).
Schritt 1 — Nenner faktorisieren & D bestimmen: x²−1 = (x−1)(x+1) (3. Binom!) → Hauptnenner = (x−1)(x+1). D = ℝ\{1; −1}.
Schritt 2 — mit Hauptnenner multiplizieren: (x+1) + 2(x−1) = 3.
Schritt 3 — auflösen: x+1+2x−2=3 → 3x−1=3 → 3x=4 → x=4/3.
Schritt 4 — Probe gegen D: 4/3 ist weder 1 noch −1, also 4/3 ∈ D → L = {4/3}.

Scheinlösungen — die Prüfungsfalle Nummer eins

Löst du die bruchfreie Gleichung aus, kann als Ergebnis genau eine der VERBOTENEN Zahlen herauskommen. Diese rechnerische „Lösung" ist keine echte Lösung — sie heißt Scheinlösung und muss verworfen werden, mit Begründung: „x=… liegt nicht in D."
⚠️ Der Fehler Nummer eins in Prüfungen: die Probe gegen D vergessen und die Scheinlösung einfach stehen lassen.

📐 Schritt für Schritt Scheinlösung erkennen

Aufgabe: Löse (x+2)/(x−4) = 6/(x−4).
Schritt 1 — Definitionsmenge: Nenner x−4=0 → x=4 verboten. D = ℝ\{4}.
Schritt 2 — mit Hauptnenner (x−4) multiplizieren: x+2 = 6.
Schritt 3 — auflösen: x = 4.
Schritt 4 — Probe gegen D: x=4 ist GENAU die verbotene Stelle → 4 ∉ D → Scheinlösung, wird verworfen. L = { }.

🌉 Brücke L = { } ist ein VOLLSTÄNDIGES Ergebnis

Aus dem allerersten Kapitel kennst du die leere Menge ∅ bzw. { } — eine Menge ohne Elemente, aber trotzdem eine gültige Menge. Genauso ist L = { } bei einer Bruchgleichung KEIN Zeichen für einen Rechenfehler, sondern das korrekte, vollständige Ergebnis: diese Gleichung hat schlicht keine Lösung.

Anwendungsaufgabe — Arbeitsaufgabe

Maschine A füllt ein Fass allein in x Stunden. Maschine B braucht dafür immer 3 Stunden länger als A. Zusammen brauchen beide 2 Stunden. Wie lange braucht Maschine A allein?
  • Ansatz: 1/x + 1/(x+3) = 1/2, mit x>0 (D=ℝ\{0;−3}, zusätzlich x>0 aus dem Sachzusammenhang).
  • Hauptnenner 2x(x+3): 2(x+3) + 2x = x(x+3) → 4x+6 = x²+3x → x²−x−6=0 → (x−3)(x+2)=0 → x=3 oder x=−2.
  • x=−2 liegt zwar in D (der Nenner wird dort nicht 0!) — aber eine NEGATIVE Zeit ergibt im Sachzusammenhang keinen Sinn und wird deshalb verworfen. Das ist etwas anderes als eine Scheinlösung: hier verwirft der KONTEXT, nicht die Definitionsmenge.
Antwortsatz: Maschine A benötigt allein 3 Stunden für das Fass.

💡 Eselsbrücke

„Aus Summen kürzen nur die Dummen" — (x+3)/3 ist NICHT gleich x! Nur ganze FAKTOREN dürfen gekürzt werden, niemals ein Summand aus einer Summe. Und: „D zuerst, rechnen danach, Probe am Ende — sonst zählt's nicht."

    Lösung anzeigenD = ℝ\{−6; 0}

    Lösung anzeigenD=ℝ\{3}. x+1=4 → x=3. Aber 3∉D → Scheinlösung → L={}.

    Lösung anzeigenWeil die leere Menge selbst eine gültige Menge ist — sie sagt korrekt aus, dass es keine Lösung innerhalb der Definitionsmenge gibt.

🎯 Prüfungs-Check — das musst du KÖNNEN

  • Definitionsmenge IMMER zuerst bestimmen, bevor gerechnet wird.
  • Scheinlösungen erkennen und verwerfen — inklusive der Begründung "liegt nicht in D".
  • L={} als vollständiges, korrektes Ergebnis akzeptieren — kein Zeichen für einen Fehler.
  • Bei Anwendungsaufgaben zusätzlich den Sachzusammenhang prüfen — manche mathematisch gültigen Lösungen ergeben inhaltlich keinen Sinn.
