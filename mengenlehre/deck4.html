Die Produktmenge A × B

🍽️ In der Mensa gibt es 3 Hauptgerichte und 4 Getränke. Wie viele verschiedene Menüs kannst du dir zusammenstellen?
A×B — jedes Gericht mit jedem Getränk verbunden
Die Produktmenge A × B beschreibt die Menge aller geordneten Paare (x|y), wobei x aus A und y aus B stammt: A × B = {(x|y) | x∈A und y∈B}. Gerichte A = {F;N;S}, Getränke B = {W;L;K;O}.
🏠 Eine Bestellkarte mit „Hauptgericht + Getränk wählen" ist im Kern nichts anderes als eine Produktmenge.

A × B ≠ B × A

Beispielaufgabe: A = {1; 2; 3}, B = {0; 1; 2}. C = A×B hat 9 Paare (x|y) mit x∈A zuerst; D = B×A hat 9 Paare mit y∈B zuerst — C ≠ D, die Reihenfolge zählt. Mächtigkeit: |A×B| = |A|·|B| = 3·3 = 9.
🏠 (Fahrer|Fahrzeug) ist etwas anderes als (Fahrzeug|Fahrer) — bei einer Zuordnungsliste macht die Reihenfolge einen inhaltlichen Unterschied.

Kurz-Reminder: A\B & Komplement

Diese zwei Werkzeuge brauchst du für die nächsten Folien — die ausführliche Definition mit Venn-Diagramm folgt im Teil „Mengen vergleichen & verknüpfen":
  • A\B (Restmenge, gesprochen „A ohne B"): alle Elemente, die in A, aber NICHT in B enthalten sind.
  • Komplement einer Menge X (bezogen auf eine Grundmenge G): alle Elemente, die in G, aber NICHT in X enthalten sind.

Kombination von Mengenoperationen

Werden drei oder mehr Mengen mit mehreren Operationen (∩, ∪, \, Komplement) kombiniert, muss zuerst die Operation in Klammern ausgewertet werden — genau wie bei einem normalen Rechenausdruck.
  • Auswertungsreihenfolge: erst der Klammerinhalt, dann von innen nach außen weiterrechnen.
  • Diese Regel machen wir uns gleich an zwei Beispielen zunutze.

📐 Schritt für Schritt D = C ∩ (A\B)

D = C∩(A\B) = {4; 5}
Aufgabe: A = {1;2;3;4;5}, B = {−2;−1;0;1;2}, C = {4;5;6;7}, Grundmenge G = ℤ. Bestimme D = C ∩ (A\B).
Klammer zuerst: A\B bestimmen — alle Elemente aus A, die NICHT in B sind: A\B = {3; 4; 5}.
Was jetzt? C ∩ (A\B) heißt „welche Elemente stehen in BEIDEN Mengen C und A\B".
Vergleichen: C = {4;5;6;7} und A\B = {3;4;5} — gemeinsame Elemente: 4 und 5.
Antwortsatz: D = C ∩ (A\B) = {4; 5}.

📐 Schritt für Schritt M = Komplement von C ∪ (B\A)

A ⊂ B, C separat, G = {0;…;10}
Aufgabe: A = {3;4;5}, B = {0;1;2;3;4;5}, C = {8;9;10}, Grundmenge G = {0;1;…;10}. Bestimme M = die Komplementärmenge von C ∪ (B\A).
Klammer zuerst: B\A bestimmen — alle Elemente aus B, die NICHT in A sind: B\A = {0; 1; 2}.
Vereinigung bilden: C ∪ (B\A) heißt „alle Elemente, die in mindestens einer der beiden Mengen stehen": C ∪ (B\A) = {0; 1; 2; 8; 9; 10}.
Komplement bilden: Jetzt alle Elemente der Grundmenge G, die NICHT in C ∪ (B\A) stehen.
Antwortsatz: M = {3; 4; 5; 6; 7}.

An einer Fach- und Berufsoberschule nehmen 500 Schüler(innen) an einer Umfrage teil: Sportverein (A), Musikinstrument (B), Jugendorganisation (C). Ein Venn-Diagramm mit drei Mengen hat 8 Regionen.

💡 Eselsbrücke

„Produktmenge = Speisekarte × Getränkekarte: jede Zeile mit jeder Spalte, Reihenfolge zählt — (F|W) ≠ (W|F)."

🔧 Praxisbeispiel Fuhrpark-Disposition

Eine Firma besitzt drei Fahrzeuge — Kleinbus (K), Mittelklassewagen (M), Straßengeländewagen (S). Drei Angestellte — Franz (F), Hubert (H), Melis (Me) — brauchen gleichzeitig einen Firmenwagen.
  • Alle möglichen (Fahrzeug|Angestellter)-Paare bilden die Produktmenge {K;M;S} × {F;H;Me} — 9 mögliche Zuordnungen.
  • Die Disposition wählt daraus genau eine passende Zuordnung pro Tag aus.

✏️ Übung: Stift & Papier

Nimm Stift und Papier — diese Aufgaben löst du von Hand, ganz ohne Bildschirm.
  1. Gegeben: A = {a;b}, B = {1;2;3}. Bilde A×B und gib |A×B| an.
    Lösung anzeigenA×B = {(a|1);(a|2);(a|3);(b|1);(b|2);(b|3)} · |A×B| = 6
  2. Gegeben: A = {2;4;6;8}, B = {4;5;6;7}. Bestimme A\B.
    Lösung anzeigenA\B = {2; 8}
  3. Gilt A×B = B×A für A = {x}, B = {y} mit x ≠ y? Begründe.
    Lösung anzeigenNein: A×B = {(x|y)}, B×A = {(y|x)} — und (x|y) ≠ (y|x), solange x ≠ y.

🎯 Prüfungs-Check — das musst du KÖNNEN

  • Eine Produktmenge A×B bilden und ihre Mächtigkeit berechnen können.
  • Begründen, warum A×B ≠ B×A gilt.
  • Kombinierte Mengenausdrücke (Klammer zuerst!) Schritt für Schritt auswerten können.
  • Aus einem Sachtext ein Mengen-Diagramm aufstellen und daraus Anzahlen ablesen können.
Transferaufgabe: An einer Schule nehmen 200 Schüler(innen) an einer Umfrage teil: „Fährst du mit dem Fahrrad zur Schule?" (A) und „Nutzt du den Bus?" (B). 90 fahren Rad, 70 nutzen den Bus, 25 nutzen beides. Wie viele nutzen WEDER Rad noch Bus?" → |A∪B| = 90+70−25 = 135. Von 200 Schüler(innen) nutzen also 200−135 = 65 weder Rad noch Bus.
