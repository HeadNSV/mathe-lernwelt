Äquivalenzumformungen

Im Jahr 825 schrieb der Gelehrte Al-Chwarizmi in Bagdad ein Buch über „Rechnen durch Ausgleichen und Ergänzen" — daraus wurde später das Wort „Algebra". Genau dieses Ausgleichen lernst du jetzt: Gleichungen systematisch lösen, mit einer Waage als Bild im Kopf.

🌉 Brücke Gleichung, Aussage & Aussageform

Verbindet man zwei Terme mit einem Gleichheitszeichen, erhält man eine Gleichung: T₁ = T₂. Besteht sie nur aus Zahlen, ist sie eine Aussage (wahr oder falsch) — genau das Konzept aus Kapitel 2! Enthält sie mindestens eine Variable, liegt keine Aussage vor, sondern eine Aussageform.
  • 4+3=7 ist eine Aussage (wahr) · 5−y=7 ist eine Aussageform — erst y=−2 macht daraus die wahre Aussage 5−(−2)=7.

🌉 Brücke Grundmenge G & Lösungsmenge L

Die Grundmenge G ist die Menge aller Zahlen, die für die Variable eingesetzt werden dürfen — meist ℝ, wenn nichts anderes angegeben ist. Die Lösungsmenge L enthält alle Zahlen aus G, die die Gleichung in eine wahre Aussage überführen.
  • Für 3−x=1 (G=ℝ) ist L={2}, denn nur x=2 macht die Aussage wahr — L ist selbst wieder eine MENGE (Kapitel 1)!
  • Gleichungen mit der gleichen Lösungsmenge heißen äquivalent, geschrieben mit dem Äquivalenzpfeil ⇔.

Was ist eine LINEARE Gleichung?

Eine lineare Gleichung liegt vor, wenn die Lösungsvariable ausschließlich in erster Potenz vorkommt.
  • 3x+4=5x−1 ist eine lineare Gleichung — x kommt nur als x¹ vor.
  • x−x²=8 ist KEINE lineare Gleichung — der quadratische Term x² macht sie zu einer anderen Kategorie (kommt in einem späteren Kapitel).

Die Waage: Addition & Subtraktion

Nimmt man auf BEIDEN Seiten gleich viel weg, bleibt die Waage im Gleichgewicht
Man erhält eine äquivalente Gleichung, wenn man auf beiden Seiten der Gleichung die gleiche Zahl oder Variable addiert bzw. subtrahiert.
  • 5x+2=3x+6 |−2 ⇔ 5x=3x+4 |−3x ⇔ 2x=4

⚠️ Anti-Regel Multiplikation & Division: NIE mit/durch 0

Man erhält eine äquivalente Gleichung, wenn man beide Seiten mit der gleichen Zahl UNGLEICH NULL multipliziert bzw. durch die gleiche Zahl ungleich Null dividiert.
Warum nicht mit 0 multiplizieren? Nimm die falsche Aussage 7=9. Multipliziert man beide Seiten mit 0, entsteht 0=0 — eine WAHRE Aussage! Die Multiplikation mit 0 verwandelt jede Gleichung in eine wahre Aussage und zerstört damit den Informationsgehalt — das ist keine erlaubte Äquivalenzumformung.

Terme auf einer Seite separat zusammenfassen

Eine weitere erlaubte Äquivalenzumformung: die Terme auf der linken bzw. rechten Seite der Gleichung dürfen jeweils SEPARAT zusammengefasst oder umsortiert werden — das verändert die Lösungsmenge nicht.
  • ½·(3x−2)=1 ⇔ 3/2·x−1=1 (linke Seite ausmultipliziert, rechte Seite unverändert)

📐 Schritt für Schritt Die 4-Schritt-Lösungsstrategie

Aufgabe: Bestimme die Lösungsmenge von (10x+6)/2 = 4·(x+2) (G=ℝ).
Schritt 1 — Vereinfachen: beide Seiten so umformen, dass dort jeweils eine Summe/Differenz steht: (10x+6)/2 = 5x+3, also 5x+3 = 4x+8.
Schritt 2 — Terme mit x auf eine Seite: |−4x ⇔ x+3=8.
Schritt 3 — Nach x auflösen: |−3 ⇔ x=5 → L={5}.
Schritt 4 — Probe: x=5 einsetzen: (10·5+6)/2=56/2=28 und 4·(5+2)=4·7=28. Wahre Aussage ✓.

💡 Eselsbrücke

„Was du der einen Waagschale antust, musst du der anderen auch antun." Jede erlaubte Äquivalenzumformung ist eine Aktion, die auf BEIDEN Seiten gleichzeitig passiert — sonst kippt die Waage, und die Gleichung stimmt nicht mehr.

🔧 Praxisbeispiel Die echte Waage in der Apotheke

Apotheker:innen nutzen bis heute Präzisionswaagen zum Abwiegen von Wirkstoffen: Legen sie ein unbekanntes Gewicht auf eine Seite und bekannte Gewichte auf die andere, bis die Waage exakt im Gleichgewicht ist, haben sie im Grunde eine Gleichung gelöst — nur mit echten Gewichten statt mit x.

Kapitel-Brücke — Transferaufgabe mit Mengenlehre: „Gegeben ist 2x−6=0 mit G=ℕ. Bestimme L und vergleiche mit der Lösungsmenge bei G=ℤ." → x=3 löst die Gleichung; da 3∈ℕ UND 3∈ℤ, ist L={3} in BEIDEN Fällen gleich — die Grundmenge bestimmt aber immer erst, ob eine Lösung überhaupt „erlaubt" wäre.
